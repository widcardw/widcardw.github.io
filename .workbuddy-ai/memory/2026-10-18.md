# 2026-10-18

## 主题切换动画：环形遮罩 → 整页淡变

用户反馈右上角主题按钮的环形遮罩（circle clip-path + View Transition）点击时会闪，希望改成整页直接切换或渐变。

改动：
- `src/components/dark/ThemeToggle.tsx`
  - 删除 `cycleTheme` 里的 `clipPath` / `endRadius` / `transition.ready` 环形动画逻辑
  - 新增常量 `THEME_TRANSITION: 'fade' | 'instant'`（默认 `'fade'`），一行可切回瞬切
  - 保留 `document.startViewTransition()`，加 `prefers-reduced-motion` 降级为瞬切
  - `realTheme` signal 与导出保留（Giscus 评论框主题依赖它）
- `src/components/dark/ThemeToggleButton.css`
  - 删掉旧的 `.dark::view-transition-*` z-index 翻转规则（环形动画专用）
  - `::view-transition-old(root)` 固定 `opacity:1; animation:none; z-index:1`（旧快照垫底不动）
  - `::view-transition-new(root)` 上层 `theme-fade-in 360ms cubic-bezier(0.4,0,0.2,1)`
  - 关键点：不做交叉淡变（old 也淡出），否则中途会透出背景，正是"闪"的来源

验证：用 playwright-core + 本地 chromium 实测亮度采样，亮 246 → 203 → 61 → 26.5 → 25.5，确认是连续渐变而非瞬切；100 页构建通过，零控制台错误。

备注：构建需 `env -u CODEBUDDY_SAFE_DELETE_BULK_STATE_DIR -u CODEBUDDY_TOOL_CALL_ID`，否则 Astro 清理 dist 会触发沙箱批量删除保护而卡住。
